# Sistem Informasi Inventaris & Consumables

Sistem manajemen inventaris berbasis web untuk mengelola barang habis pakai dan peminjaman barang operasional.

## 🚀 Fitur Utama
- **Autentikasi Multi-User**: Akses terpisah untuk Role Admin dan Staff.
- **Manajemen Barang**: Kelola data barang (Habis Pakai & Pinjaman), stok, dan satuan.
- **Form Pengambilan**: Transaksi pencatatan pengambilan barang oleh staf.
- **Tracking Peminjaman**: Pemantauan status barang yang sedang dipinjam dan riwayat pengembalian otomatis.
- **Laporan Transaksi**: Fitur cetak/export laporan ke format PDF/Print.

## 🛠️ Teknologi yang Digunakan
- **PHP Native**
- **MySQL Database**
- **Bootstrap 5**

## Cara Menggunakan Proyek Ini:
1. Clone / Download ZIP dari repositori ini.
2. Masukkan folder ke `C:\xampp\htdocs\`.
3. Buka phpMyAdmin (`http://localhost/phpmyadmin`), buat database baru bernama `db_consumable`.
4. Import file `database.sql` ke dalam database `db_consumable` tersebut.
5. Akses aplikasi melalui browser di `http://localhost/konsumable/index.php`.
